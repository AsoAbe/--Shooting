東方シューティング

東方シューティングは、3D空間を舞台に、敵から放たれる弾幕を避けながら敵を撃破する3Dシューティングゲームです。

プレイヤーは移動やジャンプを駆使して敵の攻撃を回避しながら、弾を発射して敵を攻撃します。

敵は複数の攻撃パターンを持ち、周囲への弾幕攻撃やプレイヤーへ向かって突進する攻撃などを行います。敵の攻撃を見極め、弾幕を避けながら攻撃することがゲームのポイントです。

ゲームシステム
弾幕シューティング

敵が発射する多数の弾を避けながら、プレイヤーの射撃で敵を撃破します。

敵は一定時間ごとに攻撃パターンを切り替え、プレイヤーの周囲に弾を展開する攻撃や、プレイヤーを狙って移動する攻撃などを行います。

グレイズ

敵の弾をぎりぎりで避けることで「グレイズ」を発生させることができます。

グレイズした回数を記録し、連続してグレイズすることでコンボとして扱う仕組みを実装しています。

ジャンプ・グライダー

ジャンプによって上下方向へ移動でき、空中ではグライダーを展開して空中に留まることができます。

敵の弾幕を地上だけでなく、ジャンプやグライダーを利用して立体的に回避できます。

ボス戦

ボスには複数の攻撃状態を実装しています。

周囲に弾を発射する攻撃、ランダム方向への弾幕攻撃、力を溜めてからプレイヤーへ突進する攻撃など、状態に応じて異なる攻撃を行います。

また、ボスのHPが一定以下になると攻撃パターンが変化する仕組みも実装しています。

チュートリアル

ゲームの操作やグレイズ、ジャンプなどの基本システムを段階的に確認できるチュートリアルを実装しています。

実際に操作しながらゲームシステムを理解できるようにしています。

工夫した点
オブジェクト指向を意識した設計

キャラクターや弾などの共通処理を基底クラスにまとめ、プレイヤーやボス、敵などの個別処理を派生クラスへ分けて実装しました。

例えば、CharacterBaseを基底としてプレイヤーや敵の共通処理をまとめ、StandardBossを基にボス固有の攻撃処理を実装しています。

共通処理と個別処理を分離することで、キャラクターや攻撃パターンを追加しやすい構成にしています。

ボスのステート管理

ボスの行動を状態ごとに分け、状態に応じて処理を切り替えるステートマシンを実装しました。

「通常攻撃」「ランダム攻撃」「溜め」「突進」などの状態を切り替えることで、複数の攻撃パターンを組み合わせています。

また、攻撃処理を関数ポインタで切り替えることで、状態ごとの処理を分離しています。

グレイズ判定

プレイヤーと敵弾の距離を利用して、敵弾に接触することなく近距離を通過した場合にグレイズとして判定しています。

グレイズした状態を管理することで、連続グレイズのコンボやボーナスなどのゲームシステムにつなげています。

当たり判定

プレイヤー、敵、弾などのオブジェクトに対して、それぞれの形状に合わせた当たり判定を実装しています。

カプセルなどのコリジョンを使用し、3D空間でのキャラクター同士の衝突や弾との判定を行っています。

また、通常のダメージ判定とは別にグレイズ用の判定を用意することで、敵弾との距離に応じたゲームシステムを実現しています。

スコアシステム

敵の撃破やゲームの進行状況に応じてスコアを計算するスコアシステムを実装しました。

クリア時のクリアボーナスや残りライフ、ノーダメージによるボーナス、クリアまでの時間によるタイムボーナスなど、プレイ内容に応じてスコアが変化するようにしています。

また、ハイスコアを記録して比較できるようにしています。

サウンド管理

SoundManagerを作成し、ゲーム内で使用するBGMや効果音を一元管理しています。

射撃、被弾、ジャンプ、グレイズ、敵の突進、チュートリアルの成功など、ゲーム内のイベントに合わせて効果音を再生しています。

シーン管理

タイトル、チュートリアル、ゲーム、ゲームオーバーなどのシーンを分け、SceneManagerによって各シーンを管理しています。

シーンごとの処理を分離することで、ゲーム全体の構成を整理しています。

コード設計

ObjectManagerやSceneManager、SoundManager、ScoreManagerなどの管理クラスを用意し、それぞれの責務を分離しました。

また、ゲーム内で使用する数値を定数としてまとめ、マジックナンバーを減らすことで、コードの可読性や保守性を高めています。
